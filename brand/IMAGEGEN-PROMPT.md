# ImageGen exploration prompt

Mode: built-in ImageGen

```text
Use case: logo-brand
Asset type: primary symbol and app-icon concept for Leasegate, a security
product that grants controlled, auditable access to secrets and tools for
local AI agents
Primary request: create one original abstract gateway symbol made from two
balanced geometric forms, with a precise central negative-space path subtly
suggesting both a lowercase L and a permission gate; confident, calm, modern,
security-focused without using a literal padlock, key, shield, robot, or chain
link
Style/medium: vector-friendly flat logo mark, extremely clean geometry, strong
distinctive silhouette, minimal
Composition/framing: one centered symbol only, generous even padding, square
1:1 canvas, readable at 16px
Color palette: deep midnight navy, vivid azure blue, small mint-green signal
accent; must also translate cleanly to monochrome
Background: genuinely transparent
Text: none
Constraints: no words, no letters drawn literally, no gradients, no shadows,
no mockup, no 3D, no thin lines, no tiny details, no watermark
Avoid: generic padlock icon, key icon, shield outline, fingerprint, cloud,
hexagon badge, cryptocurrency aesthetic, lettermark typography
```

The generated concept was used for silhouette exploration only. Production
assets were redrawn as deterministic, flat SVG geometry and checked again at
16 px; they do not preserve the generated gradient.
