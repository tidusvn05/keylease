# KeyLease Console: notes for coding agents

Static React SPA served by `keylease-server` (Rust). There is no JS server:
no SSR, no server functions, no Next.js/TanStack Start. All data comes from
the server's HTTP API.

## Commands (Node 26 LTS, pnpm 12)

```sh
pnpm install --frozen-lockfile
pnpm dev          # Vite dev server; proxies /v1, /healthz, /readyz to KEYLEASE_SERVER_URL (default http://127.0.0.1:8080)
pnpm lint
pnpm test         # Vitest (jsdom)
pnpm build        # vite build, then tsc -b, then the CSP check
pnpm e2e          # Playwright (needs `pnpm exec playwright install --with-deps chromium`)
pnpm api:types    # regenerate src/lib/api/schema.d.ts from openapi.json
```

## Library versions: use the current APIs

Much example code online targets older majors. Write code for these:

- **React 19**: no `forwardRef` needed (ref is a prop); no `React.FC`.
- **TanStack Router 1** with file-based routes in `src/routes/`.
  `src/routeTree.gen.ts` is generated by the Vite plugin: never edit it.
  Validate search params with Zod 4 schemas in `validateSearch`.
- **TanStack Query 5**: object syntax only (`useQuery({ queryKey, queryFn })`),
  `isPending` (not `isLoading` for first load), define reusable `queryOptions`
  in `src/lib/queries.ts`.
- **TanStack Table 9**: the API differs from v8 (`useTable` with `tableFeatures`,
  or `createTableHook`; `useReactTable` is gone, `useLegacyTable` is only for
  migration). Check `node_modules/@tanstack/react-table` types, not v8 docs.
- **Tailwind CSS 4**: configured in CSS (`src/styles.css`, `@theme`); there is
  no `tailwind.config.js`. Use theme tokens (`bg-background`, `text-muted-foreground`).
- **shadcn/ui** (new-york, `radix-ui` umbrella package): add components with
  `pnpm dlx shadcn@4.23.0 add <name>`, then check the files landed in
  `src/components/ui/` and import `cn` from `@/lib/utils`.
- **Zod 4**, **React Hook Form 7** with `@hookform/resolvers/zod`.
- **Vite 8**, **Vitest 5**, **ESLint 10** flat config, **TypeScript 6.0**
  (stay on 6.0 until typescript-eslint supports 7).

## Rules

- Strict CSP (`script-src 'self'; style-src 'self'`): no inline scripts,
  inline `<style>`, `on*=` attributes, `eval`, or CDN assets. `pnpm build`
  fails if `dist/index.html` has inline code.
- Never put secrets, tokens or vault contents in `localStorage`,
  `sessionStorage`, URLs or logs. The session is an HttpOnly cookie set by the
  server. `localStorage` is only for UI preferences (language), wrapped in try/catch.
- Call the API only through `src/lib/api/client.ts` (typed `openapi-fetch`).
  Do not hand-write request/response types; regenerate them.
- Every user-visible string goes through i18next. Add keys to both
  `src/locales/en.ts` and `src/locales/vi.ts` (the `Messages` type enforces it).
- Dependencies: exact versions only (no `^`/`~`). Do not add a dependency
  without a clear need. Install scripts are disabled (`pnpm-workspace.yaml`).
- Do not name other products as the design source in code or docs.
